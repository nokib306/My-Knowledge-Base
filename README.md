# Knowledge Base Web App (Google Sheets + Apps Script)

এই রিপোজিটরিতে Google Sheets এবং Apps Script দিয়ে তৈরি একটি সম্পূর্ণ নলেজ বেস সিস্টেমের জন্য দরকারি দুইটি ফাইল (`Code.gs` এবং `Index.html`) রাখা হয়েছে। নিচের ধাপগুলো অনুসরণ করলে খুব সহজে নতুন শীটের সাথে এই UI/ব্যাকএন্ড সংযুক্ত করতে পারবেন।

## ১) নতুন স্প্রেডশীট প্রস্তুত করুন
1. Google Drive → `New` → `Google Sheets`
2. নাম দিন **Knowledge Base**
3. Row 1 এ নিচের হেডারগুলো বসিয়ে নিন:
   - **A1:** `Date`
   - **B1:** `Time`
   - **C1:** `Category`
   - **D1:** `Content`
   - **E1:** `ID`

## ২) Apps Script এ Code.gs পেস্ট করুন
1. Sheet খুলে `Extensions → Apps Script`
2. বিদ্যমান কোড মুছে `Code.gs` ফাইলের কনটেন্ট সম্পূর্ণভাবে পেস্ট করুন
3. স্ক্রিপ্ট সংরক্ষণ করুন

## ৩) HTML ইন্টারফেস যোগ করুন
1. Apps Script এ `+ → HTML → Index`
2. নতুন ফাইলে `Index.html` ফাইলের কনটেন্ট পেস্ট করুন
3. সেভ করুন

## ৪) ডিপ্লয় (Web App)
1. `Deploy → New deployment`
2. `Web App` নির্বাচন করুন
3. `Execute as: Me`, `Who has access: Anyone`
4. অনুমতি দিন এবং ডিপ্লয় করুন
5. প্রাপ্ত URL টি ব্রাউজারে খুললেই ডার্ক থিম UI সহ সম্পূর্ণ নলেজ বেস সিস্টেম ব্যবহার করতে পারবেন

## কী আছে এই সিস্টেমে?
- ডার্ক মোড প্রফেশনাল UI
- সহজ টেক্সট এরিয়া — যা লিখবেন তাই সেভ হবে
- ক্যাটাগরি: Text, Code, Link, Idea, Photo, Other
- Google Sheet এর ৫টি কলামেই সব ডেটা সংরক্ষণ
- Instant search, edit এবং delete সাপোর্ট
- মোবাইল ও ডেস্কটপ রেসপন্সিভ ডিজাইন

## রিপোজিটরির ফাইলসমূহ
| ফাইল | বর্ণনা |
| --- | --- |
| `Code.gs` | Apps Script ব্যাকএন্ড — Sheet হেডার নিশ্চিত করা, এন্ট্রি সেভ/আপডেট/ডিলিট, সার্চ এবং ক্যাটাগরি প্রদান |
| `Index.html` | Dark UI ফ্রন্টএন্ড — টেক্সট ইনপুট, ক্যাটাগরি সিলেক্ট, সার্চ, লিস্ট ভিউ, সম্পাদনা/মুছে ফেলা |

এই ফাইল দুইটি Google Apps Script প্রজেক্টে যুক্ত করলেই নলেজ বেস অ্যাপ প্রস্তুত। শুভকামনা! 🚀
